PYsemantic Windows 便携版 v1.1.0

开始使用
1. 将压缩包完整解压到你有权限写入的文件夹。不要直接在压缩包内启动。
2. 双击 PYsemantic.exe。首次启动可能稍慢；无需安装 Python，也无需另行下载模型。
3. 在“01 数据准备”页选择 examples\synthetic_texts.csv，确认“text”为文本列、“doc_id”为 ID 列，然后点击“读取并清理”。该文件仅含合成示例文本。
4. 在“02 方法设置”页保留默认 CPU 设置，或选择“自动使用可用 GPU”。本版本包含 CPU 与 DirectML 运行时；DirectML 需要兼容的 GPU 和驱动。CUDA 运行时不包含在本便携版中。
5. 点击“开始分析”。完成后在“03 结果查看”浏览概览、文档指标、词频、近邻、主题与聚类；使用“导出选定结果”或“导出全部与比较表”保存文件。
6. 在“04 任务、日志与项目”可保存/打开项目、查看历史、管理参数预设、检查环境和导出日志。
7. 在“05 帮助与方法”点击“打开操作指南 PDF”。也可用“另存操作指南”将手册保存到指定位置。

离线与数据说明
- 下载并解压后，文本分析在本机完成，不向服务端上传语料；内置 BGE 模型已随程序打包。
- 运行日志与结果缓存保存在当前 Windows 用户的数据目录。只有在你主动保存项目时，项目包才会保存语料文本；导出结果会写入你选择的位置。
- 程序本身不需要联网。只有点击 CUDA/DirectML 资料链接时会打开浏览器；网络访问由浏览器完成。
- CPU 是默认设备。自动模式会使用当前可用的 GPU provider，否则回退到 CPU。手动选择 DirectML 后，如果设备或驱动不可用，程序会报告错误。
- 若 EXE 的环境页报告模型或运行依赖缺失，请重新下载完整压缩包。EXE 内置运行库不能通过“安装缺失依赖”按钮修改。
- TF-IDF、BGE、主题和聚类各自表示不同的文本特征；相似度不是概率或准确率，聚类结果也不是人工标签。

更详细的输入格式、参数、结果解释和问题处理请参阅“PYsemantic操作指南.pdf”、“方法说明.md”及“第三方许可.txt”。
